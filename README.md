## 사용자 confirm 게이트 (CRITICAL)

매핑 후 풀필먼트 엑셀 즉시 생성 X. **검증 보고서 먼저 → 사용자 OK 후에만 엑셀 생성**.

자동 stop 조건:
- 미매핑 > 0
- 한 코드 50%↑ 몰림 (양말 베스트셀러 화이트리스트)
- 다중 brand 카테고리에서 한 brand 100%
- 신규 옵션 패턴
- 우편번호 00000 fallback > 5%
- cross-validate 중복 > 0
