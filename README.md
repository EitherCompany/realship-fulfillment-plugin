# realship-fulfillment-plugin

사방넷 → 사방넷 풀필먼트 실배송 자동 등록 통합 플러그인.

## 핵심 기능

매일 14:00 주문 마감 후 1차/2차 사이클로 자동 실행:

1. **주문수집** — 사방넷에서 5일 범위 주문 수집
2. **일괄확정** — 미확정(001) 주문을 002 주문확인으로 일괄 변환
3. **송장미등록 다운로드** — 7일 범위 송장미등록 엑셀 자동 다운로드
4. **분류** — 빈박스(쿠팡 + 주소 %, 스마트스토어 + "문 앞에 놓아주세요!") vs 실배송
5. **매핑** — 상품번호별 + 키워드별 이중 매핑 + skip_multiplier + keywords_any 처리
6. **풀필먼트 업로드** — 이더(eithercompany) / 뉴트리(nutrijung) 계정 자동 분리 업로드
7. **state.json 차집합** — 1차/2차 사이클 간 이중처리 방지

## 워크플로 절대 순서 (필독)

```
주문수집 → 일괄확정 → 송장미등록 검색 → 분류 → 매핑 → 풀필먼트 업로드
```

⚠️ **일괄확정을 빠뜨리면** 신규 주문이 001 미확정 상태로 머무르고 002 송장미등록 검색에 안 잡힙니다. 누락의 주된 원인.

## Element-Plus 모달 처리 (computer-use 필수)

사방넷의 `el-message-box` 모달은 일반 JS click() 이벤트를 인식하지 않습니다. 반드시 `mcp__Claude_in_Chrome__computer` 의 **실제 마우스 좌표 클릭**을 사용해야 합니다:

```javascript
// ❌ 안 됨
button.click()
button.dispatchEvent(new MouseEvent('click'))

// ✅ 됨
mcp__Claude_in_Chrome__computer(action='left_click', coordinate=[878, 408])
```

## 사방넷 검색 dateDiv

기본값 `hope_delv_date` (배송희망일) + [7일] 버튼 → startDate~endDate 자동 7일 설정. **endDate 임의 연장 X**.

## 풀필먼트 페이지 freeze 우회

엑셀 업로드 [등록] 클릭 후 30초 이상 응답 없을 수 있음. 패턴: 25~30초 sleep → navigate(/order/add) reset → "엑셀 업로드 최근 이력"에서 "업로드 성공" 확인으로 검증.

## 설치

다른 PC에서 동일 결과 보장하려면:
```
/plugin install realship-fulfillment-plugin@EitherCompany
```

또는 마켓플레이스 등록 후 Cowork 업데이트 버튼.
