# 실배송 풀필먼트 반자동화 (v0.3.1)

## 🚨 v0.3.1 패치 — 9가지 결함 영구 차단

2026-05-07 사이클에서 사용자가 잡아낸 9개 결함을 영구 룰화:

1. **SKU 매트릭스 brand 분리** — 이더/루미솔이 같은 (색상,사이즈) 키에 덮어씀 → 31건 오매핑
2. **수량 룰 v3.1: N+N → ×N** — SKU 자체가 1+1 셋트인데 ×2 곱함 → 깔창 35건 ×2 잘못
3. **베개 매핑 순서: 덴코 → 슬루나 → 경추** — "덴코 ... 경추베개" 1건 오매핑
4. **영양제 N개 옵션 수량 룰 누락** — "할인이벤트: N개" / "(N개 :)" → 13건 수량 누락
5. **우편번호 raw passthrough** — `-` 포함 시 00000 fallback 너무 엄격 → 173건 모두 00000 잘못
6. **출고희망일 빈칸** — 자동 다음날 룰 폐기 (사용자 의도 미확인)
7. **동호수 쉼표 (행정구역 제외)** — `\d+동/[A-Z]+동/\d+호` 패턴 앞에만 쉼표
8. **post-cycle SKIP 룰 폐기** — 컷오프는 14:00 정각 X, 사용자 다운로드 시점
9. **state.json 거짓 기록 가능성** — 사용자 수동 처리 사이클은 state 거짓 → cross-validate 필수

### D) 수량 룰 v3.1 (CRITICAL)

```python
def setmult(option):
    # SKU가 1+1 셋트인 깔창류: N+N → ×N
    m = re.search(r'(\d+)\s*\+\s*(\d+)', option)
    if m and m.group(1) == m.group(2):
        return int(m.group(1))  # 1+1 → ×1, 2+2 → ×2, 3+3 → ×3
    # 영양제 N개 옵션
    m = re.search(r'할인이벤트[:\s]*(\d+)개', option)
    if m: return int(m.group(1))
    m = re.search(r'(\d+)개\s*:', option)
    if m: return int(m.group(1))
    return 1
```
