## 매 사이클 워크플로우 (반자동화 5단계)

### 👤 Step 1: 사방넷 주문수집 (사용자, 1분)
1. `https://sbadmin03.sabangnet.co.kr/#/order/order-collect-auto` 접속
2. 수집기간: 6일치 (빨간날·주말 자동수집 봇 멈춤 대비)
3. 7개 mall row 모두 선택
4. "주문수집(신규+주문확인)" 클릭

### 👤 Step 2: 사방넷 일괄확정 (사용자, 30초)
1. `#/order/order-decide` 접속
2. 수집일자 6일치, 주문선택 = 주문미확정
3. 검색 → 일괄주문확정 → 확인

### 👤 Step 3: 사방넷 엑셀 다운로드 (사용자, 1분)
1. `#/order/order-confirm` 접속
2. 좌측 "신규주문" 클릭
3. 일자: 시작 = 사이클 시작일, 종료 = 오늘
4. 선택사항I 우측 "송장미등록" 체크 → 검색
5. 우측 "주문서출력양식선택" → 양식1 (또는 테스트 양식) → 다운로드
6. **채팅에 엑셀 업로드** ← Claude가 트리거됨

### 🤖 Step 4: Claude 매핑·풀필먼트 엑셀 생성 (자동, 30초)

```bash
python3 <skill-path>/scripts/create_fulfillment_excel.py \
  --orders <업로드된 엑셀> \
  --sku-master <(가능하면) 풀필먼트 재고조회 엑셀> \
  --state <Downloads>/realship_state.json \
  --cycle-start "YYYY-MM-DD HH:MM" \
  --output-ether <Downloads>/풀필먼트_이더_YYYYMMDD.xlsx \
  --output-nutri <Downloads>/풀필먼트_뉴트리_YYYYMMDD.xlsx \
  --report <Downloads>/실배송_리포트_YYYYMMDD.json
```

실행 흐름:
1. 엑셀 파싱 (양식1 또는 테스트 양식)
2. 사이클 이전 SKIP
3. 빈박스 SKIP (쿠팡 주소% / 스마트 '문 앞에 놓아주세요!' 정확매칭)
4. 실배송 추출 → 상품 매핑
5. state.json 차집합 가드
6. 이더(E*) / 뉴트리(N*) 풀필먼트 업로드 엑셀 생성
7. 특이사항 리포트 자동 작성

### 👤 Step 5: 풀필먼트 업로드 (사용자, 5분)
1. 이더 계정 로그인 → 발주등록 → 엑셀등록 → 이더 엑셀
2. 로그아웃 → 뉴트리 계정 → 뉴트리 엑셀

## 매핑 로직

### A) 풀필먼트 SKU 마스터 매트릭스 자동 빌드

사용자가 풀필먼트 재고조회 엑셀(615 SKU)을 업로드하면:

| 카테고리 | 룰 | 코드 수 |
|---|---|---|
| 구름깔창 (이더+루미솔) | (색상, 사이즈) → E* | 24 |
| 벌집/메쉬 깔창 | (사이즈) → E* | 6 |
| 양말 | (색상) → E* | 13 |
| 글램루아 브라 | (색상조합, 사이즈) → E* | 24 |
| 아쿠아슈즈 | (색상, 사이즈) → E* | 39 |
| 베개 | 직접 룰 | 3 |

### B) 영양제 키워드 룰 22종 (뉴트리)

글루타치온, 브로멜라인, 멜라토닌(5mg/2mg), 알파CD/알파시클로덱스트린/알파씨디/알파시디, 콜린+미오이노시톨, 비오틴, 초임계 알티지/rTG/오메가3, PS70/포스파티딜세린, 밀크씨슬, 비타민D, 멀티비타민, 루테인, 마그네슘, 비타민B, 상어연골

### C) 색상 정규화 (양방향)

블랙 = 검은색 = 검정 / 그레이 = 회색.
SKU 매트릭스는 원문 색상 그대로 인덱싱, 매칭 시 양쪽 다 검색.
(v0.2.5의 정규화 후 SKU "블랙" 매칭 실패 버그 수정)

### D) 수량 룰 v2

`풀필 수량 = ordQty × set_multiplier(옵션)`. `1+1` → 2배, `2+2` → 4배, `N세트` → N배.

### E) 사용자 fallback

- 빈 전화 → `010-0000-0000`
- 빈 우편번호/잘린 우편번호 → `00000`
- 빈 주소 → `주소 사방넷 자동입력`
