# 실배송 풀필먼트 매핑 운영 원칙

**이 파일은 플러그인 번들의 필수 구성 요소입니다. 스킬 실행 시 반드시 로드되어야 합니다.**

## 🔑 핵심 원칙 3가지

### 원칙 1: 풀필먼트 상품명 앞부분 일치 원칙

사방넷 풀필먼트에 신규 상품을 등록할 때 **상품명은 스마트스토어 원본 상품명과 앞부분이 최대한 동일**하게 입력한다.

- 스마트스토어 상품명은 보통 40-50자
- 풀필먼트 등록 상품명: **앞부분 30-40자까지 원본과 일치**
- 사방넷 풀필먼트 상품명 길이 제한으로 뒷부분이 잘릴 수 있으므로 핵심은 앞부분에 배치
- **목적**: 매핑 엔진이 원본/풀필먼트 상품명을 직관적으로 매칭할 수 있고, 크로스체킹 엑셀에서 사람이 눈으로도 구분 가능

**예시 (구름쿠션깔창)**
- 스마트스토어 원본: `바디인솔 1+1 기능성 구름 푹신한 쫀쫀 쿠션 신발 깔창 아치 운동화 군인 군대 족저근막염`
- ✅ 개선된 풀필먼트 상품명: `바디인솔 1+1 기능성 구름 푹신한 쫀쫀 쿠션 신발 깔창`
- ❌ 기존(애매한) 풀필먼트 상품명: `바디인솔 1+1 발편한 푹신한 깔창`

**예시 (아치기능성깔창)**
- 스마트스토어 원본: `바디인솔 1+1 푹신한 쿠션 발편한 신발 깔창 평발 벌집 메쉬 기능성 아치 군인 족저근막염`
- ✅ 개선된 풀필먼트 상품명: `바디인솔 1+1 푹신한 쿠션 발편한 신발 깔창 평발 벌집 메쉬`
- ❌ 기존(애매한) 풀필먼트 상품명: `바디인솔 1+1 아치 기능성 발편한 깔창`

### 원칙 2: 매핑 애매 카테고리 사전 확인

같은 카테고리 내에 유사 상품이 여러 개 등록되어 있는 경우, 매핑 엔진을 신뢰하지 말고 **사용자에게 사전 확인 요청**한다.

**사전 확인 대상 카테고리** (현재 기준 — 상품 추가 시 갱신)
- 깔창 (구름쿠션 vs 아치기능성)
- 브라 (글램루아 사이즈/컬러 조합 다수)
- 영양제 (뉴트리정 고용량/일반 구분)
- 무릎보호대 (가드웰 수량/색상/사이즈)

**확인 절차**
1. 크로스체킹 엑셀에 `원본상품명 ↔ 매핑상품명` 대조 컬럼 포함
2. 같은 카테고리 내 여러 SKU로 매핑된 경우 카테고리별 요약 표 제시
3. 사용자 OK 후에만 풀필먼트 업로드 진행

### 원칙 3: product_mapping.json 유지보수

**배타적 키워드 유지**
- 같은 카테고리 내 여러 규칙이 있을 때, 각 규칙마다 배타적 키워드를 `keywords_all` 또는 `keywords_any`에 둠
- 겹치는 경우 배열 순서(index)가 우선순위이므로 해당 규칙을 상단으로 이동하거나 배타 키워드 추가

**lint 체크 항목 (새 규칙 추가 시)**
- [ ] keywords_all: 원본 상품명 앞 30자 이내에 있는가?
- [ ] keywords_any: 다른 규칙과 겹치지 않는가?
- [ ] 같은 카테고리 기존 규칙이 있다면 배타성 확보됐는가?

**모범 사례 (깔창 분리)**
```json
{
  "name": "아치기능성깔창",
  "keywords_all": ["깔창", "벌집 메쉬"],
  "사이즈_매핑": { ... }
},
{
  "name": "구름쿠션깔창",
  "keywords_all": ["깔창"],
  "keywords_any": ["구름", "쫀쫀"],
  "색상_사이즈_매핑": { ... }
}
```
